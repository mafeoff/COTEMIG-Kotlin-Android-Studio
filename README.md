# Android Development / Kotlin — DEVIOS 3C2 2023

Projects and exercises developed with **Kotlin** and **Android Studio** as part of the COTEMIG technical course in 2023.

The repository contains practical Android development activities covering layouts, multiple-screen navigation, Toast messages, RecyclerView, API integration with Retrofit, and character-based applications.
